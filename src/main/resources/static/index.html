    Você envia. A gente ajuda a conferir.
    Conferimos os dados encontrados, a data de emissão e o nome informado. O resultado fica no histórico deste computador para você consultar.
    
        
    01
    Documento
    Você envia um PDF, PNG ou JPG e informa o nome do titular. O servidor verifica o formato e os limites.
    Escolha
    02
    Leitura
    OpenCV prepara as imagens e Tesseract reconhece o texto. PDFs com texto selecionável podem ser lidos diretamente.
    OpenCV + Tesseract
    03
    Extração
    O texto é organizado em campos: nome, CPF, endereço, cidade, UF e emissão. Campos não encontrados ficam vazios.
    Extrator local
    04
    Validação
    Java confere os campos, a data de emissão e o nome informado. O resultado e as regras são salvos no banco.
    Spring Boot + banco
    
        
    Teste em três passos
    1. Baixe o comprovante fictício pelo botão Baixar exemplo.
    2. Em Conferir documento, informe Ana Silva como titular e selecione o PDF.
    3. Clique em Conferir meu documento e confira os dados e as regras do resultado.
    Antes de enviar
    O documento precisa trazer nome, CPF, endereço e uma data de emissão recente. Informe o nome completo do titular para a comparação.
    Uma reprovação mostra o que não passou na conferência. Confira a leitura, envie uma imagem mais nítida ou use um comprovante recente. Não altere os dados do documento original.
